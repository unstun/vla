# VLA Literature Survey

Read relevant existing notes and `.pipeline/literature/index.md` first.
Define the question, selection criteria and useful comparison dimensions.
Use available search tools, then inspect primary papers, official project
pages, dataset cards or canonical repositories for each consequential claim.
No separate search agent or generic research skill is required.

Compare methods, inputs and action interfaces, evaluation conditions, actual
results, limitations and relevance to Lite3. Cite primary URLs or local source
paths. Distinguish paper claims from personally executed results. Use
`paper-analyzer` for a detailed single-paper reading and `inno-code-survey`
for repository selection or pinned acquisition.

When saving is part of the request, follow existing `.pipeline/survey/` formats,
use `origin` and `reviewed: false`, and update the relevant literature index.
Keep papers under `docs/research/papers/` by CitationKey. Download only sources
needed for the task; unavailable content is a named gap, not an invented result.
