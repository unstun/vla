## Runtime strategy

from the accepted execution copy. Preserve container paths /task,/work,/source
so colcon caches and library prefixes keep their meaning. Inspect parent-prefix
chains and transfer only needed underlays or assemble verified local_setup
prefixes. Verify original source/install bytes before and after execution.

Use the pinned Python3.12 environment in an isolated user prefix, with a
relocatable base interpreter or a rebuilt same-version venv as required. Keep
editable/runtime path relocation explicit. Preserve the ARM factory library
and image; use existing ARM execution support or an isolated user-space
emulator, never global binfmt/driver changes. Record image logical/config IDs.

Replace v233's historical verification closure with direct frozenv232/v233 and
actual input identities. Replace the host GPU-empty check with bounded CPU/RAM/
port admission and peer-job continuity records; CPU physics does not require
stopping IsaacLab. Host adaptation is not a change to collision admission.
