# SCAN curve and reference-progress pitfalls

Evidence root: `.pipeline/experiments/2026-09-23_scan_reactive_stair/`
`runtime_integration/repairs/2026-09-26_sequential/`.

1. **World twist mislabeled as body twist in recorded replay.** The live bridge
   already publishes body twist, but the old extractor/publisher placed world
   vectors under `child_frame_id=base`, causing a second world rotation in FSM.
   Step13 retains direct body/world vectors from the same physics row, tests
   frame handling and preserves old artifacts. Historical replay cannot prove
   exact measured-world velocity continuity. Zero start acceleration is supplied,
   not measured.
2. **Clear graph edges do not imply a clear fitted curve.** Step16 queries the
   original recorded curve at the same body/map/clock. Execution heading and
   small geometric deviations trigger WrongHeight/UnknownSupport even when
   parent-edge poses are clear. Step17 replaces coarse optimizer coverage with
   the existing complete checker, preserving the independent final gate.
3. **A guidance error log alone is not the cause of a rejected curve.** The
   accepted old input also logs initial AStar pool exhaustion. Step18 instead
   captures the failed retry endpoints, proving a strict three-node repair path
   where endpoint adjustment failed. scan31 changes only actual repair calls.
4. **More stored constraints do not prove convergence.** Step20 confirms the
   returned failed trial is still colliding; seven control planes do not cross
   its observed two-node repair path. Step21 restores six valid real-map pairs
   but reaches the unchanged21-rebound bound. The cancelled LBFGS wrapper returns
   last callback controls, not necessarily its internally rolled-back vector.
5. **A proposed local target is not accepted progress or the global goal.** Old
   FSM writes progress before manager success and truncates full duration/end
   when the target is occupied. scan33 native tests reproduce both and verify
   proposal/commit separation. Its finite-reference checks must precede every
   map query. Shared prefix budget includes rejected endpoints.
6. **Live sensor-origin Unknown remains unresolved.** Earlier records identify
   an unobserved origin voxel and a ray iterator that omits its terminal origin
   cell. Startup history/pose-cloud timing differs from full-history replay.
   Do not claim a unique complete cause or free the origin without evidence.
