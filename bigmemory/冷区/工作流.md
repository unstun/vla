# Working patterns with Dr Sun

Each item names its source. An item that is not recorded in a project file is marked as such.

- **"Continue" means use the recommended defaults.** When Dr Sun declines a design dialog and says "continue",
  apply the lead's recommended defaults, record them as a lead proposal that he may override, and ask again only
  at real gates: run budget, remote or robot execution, scope and thresholds. Source:
  `.trellis/tasks/archive/2026-09/09-17-isaac-runner-stance-hold/prd.md` D2 and D3. (2026-09-17)
- **Run long series drivers detached and recover, never re-run, a finished episode.** A background task started from
  a Claude session dies with that session, so start series drivers with `nohup … &` and follow the ledger. If the
  local driver dies after the remote result is final, collect and review that episode with the launcher's own
  steps instead of re-running it. Source: `.trellis/spec/backend/simulator-inference-evidence.md`, section "Stance
  hold, post-result amendments and interrupted series" (added 2026-09-18 UTC). (2026-09-17)
- **Fix selection rules and new acceptance criteria before the runs they judge.** Record them in the PRD first
  (stance-hold D4 added AC7 before the rerun; D5 fixed AC8 and the variant selection rule before any walk run).
  Any later change follows the post-result amendment rule in `偏好.md`. Source: stance-hold PRD D4–D7. (2026-09-17)

- **Restoring upstream files must retain reviewed safety repairs deliberately.** Check the actual restored file against prior fixed call sites, then replay the old negative tests; a helper remaining in the tree does not prove its callers use it. Evidence: native_optimizer restore receipt and finite-constraint counterexamples in the2026-09-28 Newton archive.
- **Configuration tests must cover the real loading and transport path.** Compare resolved settings, wire requests and native route results; direct planner preflight missed explicit-null loss. Evidence: Newton versions/v26/native_chain.
- **Check for a stale `.git/index.lock` before any archive or backup commit.** If the lock exists, record its age
  and size and check for a running git process. Then report it to Dr Sun and ask before removing it. Do not just
  "preserve the existing lock" from session to session. A 0-byte lock from 2026-10-01 02:46, with no git process
  behind it, blocked all staging until 2026-10-13, while journal sessions 28–33 recorded it only as pre-existing.
  Source: `.trellis/workspace/sun/journal-1.md` sessions 28–33 and the 2026-10-13 archive check
  (`bigmemory/冷区/心路历程/2026-10-13.md`). (2026-10-13)
- **Design diagnostic conditions inside existing project contracts.** Before choosing test conditions, check the
  operating contracts already in force, for example the 0.6 m/s minimum planned cruise from v7. A condition
  outside them is a labelled control and is not generalized. Dr Sun caught v179's sub-0.6 m/s stop tests.
  Sources: `.pipeline/survey/2026-10-12_rl_zero_command_upstream_survey.md`, section "Minimum-speed correction,
  2026-10-13", and the v179–v183 entry in the Newton `versions/README.md`. (2026-10-13)
- **Judge a navigation candidate against an unchanged control run on the same host in the same period, and never
  pool cohorts.** Keep Mac and Linux, candidate and control, and earlier and later cohorts separate. The v188
  unchanged-source rebuild arrived 3/5 while the existing v177 binary arrived 5/5. Five-run cohorts are
  therefore weak evidence about a candidate's effect. Sources: the v186–v188 entries in the Newton
  `versions/README.md` and
  `.pipeline/experiments/2026-09-26_newton_stair_reproduction/audits/2026-10-13_terminal_repair_review/REPORT.zh.md`.
