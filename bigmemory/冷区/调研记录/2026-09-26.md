# macOS simulation capability check

On the current Mac, hardware inspection reports Apple M5 and32GB. Native SCAN
source-method tests run locally. MuJoCo is absent from the two inspected Python
environments; this is not a whole-machine environment inventory.

The [official MuJoCo repository](https://github.com/google-deepmind/mujoco#installation)
supports macOS universal binaries, and its
[Python viewer documentation](https://mujoco.readthedocs.io/en/stable/python.html#passive-viewer)
specifies `mjpython` for the passive macOS viewer. The existing VLA Lite3 MuJoCo
adapter can be an adaptation starting point, subject to runtime validation.

The [Isaac Sim5.1 requirements](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/requirements.html)
do not support this Apple Silicon Mac: desktop targets require NVIDIA RTX
hardware and Linux/Windows, with aarch64 limited to DGX Spark. Thus an adapted
local simulator cannot substitute for the current RTX LiDAR/official-human
acceptance without declaring and validating that changed test condition.

No simulator was installed or launched. Exact local commands and scope are in
[the capability record](../../../.pipeline/handoffs/2026-09-26_scan_stair_archive/LOCAL_SIMULATION.md).
