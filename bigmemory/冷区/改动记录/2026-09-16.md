## Changes And Evidence

- The selected architecture is the real Pi agent loop with Cortex/EMOS-compatible
  robot tools over the existing Isaac Lab / Lite3 V12 / native PCT and SCAN
  stack. The imported navigation bridge is pinned to
  `848b4aecd01237805e0564c88d3ba09146fd2353`. The fixture gateway uses compatible
  schemas; it does not import or execute Cortex. See the
  [task design](../../../.trellis/tasks/09-16-emos-harnessvln-reimplementation/design.md)
  and [backend source manifest](../../../references/upstream/2026-09-16_lite3_isaac_harness_backend/repository_manifest.yaml).
- The offline Pi protocol slice passed 11 Python and 5 Pi/transport checks on
  both local and Linux hosts, with 11/11 returned artifact hashes matching.
  Its two movements are scripted fixture calls, with no real model, ROS or
  sensing execution. The separate persistent navigation service passed 37
  executor and 21 independent fault/ordering tests. Evidence:
  [P1 result](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/RESULT.md)
  and [P2A lead review](../../../.trellis/tasks/09-16-emos-harnessvln-reimplementation/research/acceptance/P2A_LEAD_REVIEW.md).
- Native PCT, the compiled Foxy SCAN planner/controller and Lite3 V12 ran in one
  continuous Isaac episode, `two_goal_20260916T162236Z_p2b_actual4`: depart for A,
  cancel while moving, confirm stillness, replan to A, arrive at A, then B and
  stop. It took 16.52 simulation seconds, with 3.919 m horizontal travel,
  0.179/0.154 m A/B arrival errors, no resets or pose injections, and zero
  non-foot contact force. Independent acceptance passed 41 checks; 34/34
  returned hashes matched. This remains one known-map, simulator-truth pilot.
  Evidence: [P2B result](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/P2B_RESULT.md)
  and [raw acceptance](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/p2b_execution/qualification/actual4_lead_review/result.json).
- A passive latest-only point-cloud viewer and resource sampler were added.
  Actual NVIDIA RViz rendering and `h264_nvenc` recording were verified on
  gpu5070ti. The GPU display wrapper is the default profile. OFF, software RViz
  and GPU RViz runs each covered 45 simulation seconds; all three later
  navigation attempts failed after A resubmission. Display success therefore
  does not close the navigation reliability gate. Hash returns matched
  38/38, 46/46 and 47/47; a separate run-specific-window startup qualification
  matched 10/10. Evidence:
  [display result](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/pointcloud_display/RESULT.md)
  and [GPU comparison](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/pointcloud_display/gpu_comparison.json).
- The SCAN failure was reproduced with its real native C++ manager in an
  isolated diagnostic package. An incorrect endpoint acceleration was isolated;
  a one-line candidate using the true polynomial end passed all 12 diagnostic
  calls without changing limits. Both original and candidate returned 16/16
  matching artifacts. Production `scan_03` and its materializer remain unchanged.
  Evidence: [diagnosis](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/scan_replan_diagnosis/RESULT.md),
  [comparison](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/scan_replan_diagnosis/comparison.json)
  and [independent review](../../../.pipeline/experiments/2026-09-16_pi_cortex_harnessvln/scan_replan_diagnosis/independent_review.json).
