## 2. v37/v38 比较后采用 v40 CPU 求解器图回放

- 改动：v37 增加显式设备选择；v38 CUDA 仅捕获求解器，两组状态方向各自回放。原 1 ms PD、碰撞、容量、实际力和有限值检查仍逐步执行，20 ms 策略周期不变。v40 将同样图回放用于 CPU，v41 集成已通过的 CPU 图与 v39 缓存。
- 验证：v37 CPU 与原 CPU 200 行闭环逐位相同；CUDA eager 无提速。v38 CUDA 图物理 RTF 约 1.58，但固定目标重放关节差 0.007906556 rad，超过预设 0.001 rad，未采纳 CUDA。v40 连续 4.1 s、200 行完整闭环与原 CPU 精确相同，4,099 次回放及逐步安全门通过，零指令阶段 RTF 1.584524；不含完整传感/通信。证据 `audits/2026-09-30_gpu_device_compare/`、`versions/v40/RESULTS.md`、`versions/v41/component_qualification.json`。
- 未来用途：已采用的是数值合格 CPU 路径；CUDA 的速度结果不能替代数值门，更不能倒推整套导航实时。v41 本身无物理导航跑。

## 3. v39/v44 缓存纯原始占用分类，保持几何结果

- 改动：v39 在同步 rebound 求解域缓存原始膨胀贡献者分类，真实地图/点云/地面/边界改动前失效。v44 将外层域扩大到完整同步执行回调，嵌套尝试复用，空传感输入 drain 不清空；域退出清空，实时支持、位姿、新鲜度与最终碰撞判断保留。
- 验证：5070Ti 原生编译通过。v39 缓存 46 项 + 原生契约 34 项，v44 缓存 48 项 + 原生 34 项；完整 v32/v33 几何 JSON 与 v36 attempt09 精确相同。v39 为 17.648244 / 22.788101 ms，v44 为 11.758781 / 12.763442 ms。冻结 harness 错误父文件名造成的 false 字段保留，正确比较分别见 `versions/v41/component_qualification.json`、`versions/v45/component_qualification.json`。
- 未来用途：这是已实施的单回调缓存；跨回调 revision 缓存、可行窗口提示和上一轨迹初值仍只是方案。源 `runtime/scan68_raw_contributor_cache_v39/`、`runtime/scan69_shared_attempt_cache_v44/` 不应与拟议优化混写。
