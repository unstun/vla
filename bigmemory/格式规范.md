# Bigmemory Format

## Hot zone

The hot zone contains only current state:

- `热区/状态简报.md`
- `热区/未关闭决策.md`
- `热区/近期改动.md`

Refresh it when a task changes durable project state.

## Cold zone

Cold-zone records are append-only, source-backed summaries grouped by purpose.
Each record should include date, task, decision or evidence, affected paths,
verification, and commit when available.

Do not copy status or conclusions from `machine-dog-nav`, `machine-dog`, or any
upstream project unless the VLA project explicitly depends on a pinned interface
artifact. A baseline import does not import the source project's task or
experiment history.
