# NaVILA 8B NF4 inference on RTX 5070 Ti

Date: 2026-09-08. Stage: experiment and analysis.

The actual pretrained NaVILA VLA completed 11 recorded-image inference calls on
the 16 GB RTX 5070 Ti. Its language backbone contained 224 CUDA `Linear4bit`
layers with initialized NF4 quantization state; all model parameters were on
`cuda:0`. Vision and projector stayed FP16. The exported NF4 checkpoint was
loaded in a fresh process and produced exactly the same greedy output IDs for
the repeated input. This is NF4 deployment evidence, not the paper's AWQ result
or a closed-loop navigation result.

## Measurements

| Measurement | Observed value |
| --- | --- |
| Original checkpoint load / on-load quantization | 4.308 s |
| Model CUDA allocation after loading | 6.312 GiB |
| Peak CUDA allocation during inference | 7.793 GiB |
| Peak sampled total GPU memory | 9,448 MiB = 9.227 GiB |
| First model-generation call | 2.044 s |
| Median of the following ten calls | 0.731 s |
| First run, including export and hashing | 25.696 s |
| Exported model size | 6,639,920,469 bytes |
| Exported model reload | 1.175 s |
| Reload probe including startup and inference | 5.372 s |
| Local artifact hashes checked | 24 first-run + 13 reload-run files |

The timing includes GPU-synchronized generation but not network transfer or
simulator rendering. Every call supplied eight processed RGB frames at
`[8, 3, 384, 384]`; cold-start cases used the upstream black-padding rule.
The first call includes warmup. Prompt/output lengths differ across cases, so
the median is a workload observation, not a universal FPS guarantee.

## Raw action findings

Both recorded initial images produced the same pattern:

| Instruction | Output |
| --- | --- |
| `直走，并在自动售货机前停下` | `The next action is turn left 45 degree.` |
| `Go straight ahead and stop at the front of the vending machine.` | `The next action is move forward 75 cm.` |
| `向前直走 3 米，然后停下` | `The next action is turn left 45 degree.` |
| `Go straight forward for 3 meters, then stop.` | `The next action is move forward 75 cm.` |

The first Chinese case was repeated exactly and returned identical output IDs.
The two additional cases used eight raw frames from an earlier TIC-VLA episode,
ending near the vending machine. Both Chinese and English produced
`I think I should stop because I have finished the instruction.`

These initial Chinese actions do not follow the requested straight movement.
The English 75 cm output is one intermediate action, not proof of stopping at
3 m. The near-goal stop texts are not evidence of executed stopping: the images
were replayed and no NaVILA-controlled robot moved. No FP16 comparison was run,
so the language discrepancy cannot be attributed specifically to quantization.

## Deployment and reproduction

The reusable environment, source copy and exported 6.64 GB NF4 payload are on
`gpu5070ti` under `/home/sun/vla_exec/2026-09-08_navila_8b_quantized_5070ti`.
Source, configuration, input fixtures, raw results and hash manifests are synced
and checked locally. The large derived model payload itself has not been copied
to the Mac. This is a remaining payload-mirroring item, separate from the passed
inference test. The public original checkpoint is pinned and the NF4 artifact
can be regenerated by the retained download/probe scripts.

On `gpu5070ti`, from the execution directory, repeat the saved-weight probe with
a new run ID:

```bash
venv/bin/python scripts/run_bounded.py MY_NEW_RUN_ID --reload
```

Each invocation is limited to 600 s. `fixtures/requests.json` contains the
verbatim instructions and input image lists. Updating inputs requires updating
the package manifest through the local source directory and syncing it first.
The CLI writes files; no web UI or public inference port was started.

All task-owned model/download processes ended. The final GPU snapshot was
252 MiB and 0% utilization. Simulator integration and shared-GPU capacity remain
untested; the prior large Isaac hospital scene cannot be assumed to fit alongside
this larger VLA merely because model-only inference fits.

## Setup failures and scope

The first dependency download failed its hash and was rejected; normal retry
succeeded. Bulk uploads were unreliable and were completed with bounded SSH
writes. Ten stalled model ranges (320 MiB) required a final curl retry with a
hard deadline; all final file hashes passed. The last retry log's throughput
counter includes already retained parts and must not be read as network speed.
See `setup/superseded_attempts.md` and the retained setup logs.

The paper uses RTX 4090 at roughly 1 FPS. The public NaVILA-Bench simulation
client uses length-prefixed JSON over TCP, with JPEG/base64 images and an action
text reply, defaulting to localhost. That does not establish the exact wireless
network used by the authors' real robots. See README for primary-source links.
