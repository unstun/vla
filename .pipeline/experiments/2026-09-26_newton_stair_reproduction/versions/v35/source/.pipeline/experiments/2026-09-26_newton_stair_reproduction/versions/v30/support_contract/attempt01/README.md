# Support contract, attempt 01

The first contract run (15 synthetic cases, pinned Building grounds, node
delivery orders) passed. `contract_results.json` here is its verdict, and the
scripts and sources beside it are the exact files it used.

The independent review then asked for a stronger contract before freezing:
- an integration-level real-drop negative;
- a half-cell evidence offset that separates centre mapping from index or
  corner mapping;
- an ambiguous navigation-neighbour case;
- absent neighbours with evidence at a different level;
- timing of the rescoring.

The contract one level up supersedes this attempt. Nothing here was changed
after the run.
