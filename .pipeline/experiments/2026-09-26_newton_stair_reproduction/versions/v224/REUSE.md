# Reuse and local changes

- Existing imported PCT/SCAN baseline: community `yagami-light7/PCT-SCAN-ROS2` at `1cf45a1c12ca785ce533293302be09d51daf0ccb`; author references `byangw/PCT_planner` at `35cd73fd82bcd51bc538429294af7646b2a09815` and `wuyi2121/SCAN-Planner` at `348e8a590a50a5a6bbab8d8c6dcfd171f009be26`. Original source/license/run records remain in `references/upstream/2026-10-16_pct_scan_origin_audit/`. This is an overlay on the already imported and tested local sources, not a new upstream import or new upstream-reproduction claim.
- PCT retains its A*, GTSAM WNOJ/WNOA smoothing and interpolators. Only a separate nonnegative graph cost and independent optimizer residual are added. The native `.hpp` interpolator headers are now exported alongside `.h` headers for installed consumers.
- SCAN retains its cubic spline optimizer, L-BFGS and hard validators. The new term evaluates spline samples and propagates position/lookahead-heading derivatives to the existing control points.
- The native physical-floor association, endpoint terrain classification and ETH StepFilter adaptation are reused by the static export. The ETH source pin and BSD-3-Clause attribution remain in `eth_step_score_adaptation.h`. The added below-floor annotation applies only to the new static soft view; mixed nonterrain evidence wins and online occupancy is untouched.
- PCL's existing `KdTreeFLANN` performs radius queries over the declared static nonterrain voxel centers. PCL is an inherited container dependency, not vendored a second time. Official API: https://pointclouds.org/documentation/classpcl_1_1_kd_tree_f_l_a_n_n.html . Its installed version is bound by the existing Docker image receipt; the online API page is not a claim that the container uses its current development version.
- v223's independent geometry oracle uses isolated `python-fcl==0.7.0.8`; FCL is not linked into either planner. The exact replay predicate is compared on 5,000 seeded cases. Results and regeneration script are retained in v223.

New local code is the immutable static evidence reader/evaluator, versioned exporter and the three consumer adapters. No OCS2 controller, contact planner, Nav2 costmap, recovery connector or additional online mapper is introduced.

The target margin starts at 0.15 m and is a tunable experiment parameter. Clearance penalties saturate at zero above target. Terrain difficulty, support-edge margin and static-solid margin remain distinct; planner-specific route-length/dynamics/smoothness weights remain separate. Static point-cloud distance does not certify unseen live space or future leg contacts.
