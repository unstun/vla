# VLA Research Pipeline

This directory stores reviewed project knowledge. It does not prove that a
paper result or upstream repository has been reproduced.

## Status labels

- `surveyed`: primary material was inspected.
- `reproduced`: the upstream procedure was run with recorded evidence.
- `imported`: a pinned source snapshot exists inside this repository.
- `integrated`: the behavior works inside `/Users/sun/vla`.
- `validated`: the declared project acceptance test passed.

## Directories

- `literature/`: paper and upstream repository index.
- `survey/`: source-backed research reports.
- `experiments/`: pre-run decisions and append-only run records.
- `terminology/`: project terminology source of truth.
- `templates/`: reusable project record templates.
- `codex_tasks/`: external or offline task packages.

Every research or experiment record should declare its origin and review state.
AI-only notes are leads, not decision evidence.
